# Syntra Labs — Professional Storefront

Redesigned storefront with responsive navigation, premium dark visual system, product catalogue, mobile cart drawer, Stripe checkout hooks, Supabase catalogue integration and private /admin route.

## Run
npm install
npm run dev

## Production
Keep secrets in Vercel Environment Variables. Do not commit .env.local.

## Admin
The admin route still exists at /admin but is intentionally not linked from the public storefront.
